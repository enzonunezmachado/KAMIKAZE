# Templates web

## Arquivos
- [starter.html](starter.html): ponto de partida de uma página institucional simples.

## Como usar
1. Copiar o arquivo para a raiz do novo site.
2. Copiar os assets canônicos de `portfolio_site/docs/assets/` para a pasta `assets/` do novo projeto.
3. Ajustar os caminhos de CSS/JS para `assets/kamikaze-base.css` e `assets/kamikaze.js`.
4. Substituir conteúdo de exemplo e ajustar identidade/conteúdo ao objetivo real.
5. Seguir o [guia de desenvolvimento](../AI_WEB_DEVELOPMENT_GUIDE.md).

O template é uma base estrutural, não uma página pronta para publicar sem revisão.
