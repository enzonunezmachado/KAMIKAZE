# Templates operacionais — índice

Modelos vazios para iniciar registros. Copie e preencha apenas quando uma iniciativa for aprovada.

- [IDEA_TEMPLATE.md](IDEA_TEMPLATE.md) — registrar uma hipótese/oportunidade sem tratá-la como negócio validado.
- [EXPERIMENT_TEMPLATE.md](EXPERIMENT_TEMPLATE.md) — definir teste, público, oferta, canal, métrica, critério de parada e autorização.

## Regra

Templates não são registros ativos. Os documentos preenchidos devem ir para o módulo correspondente (opportunities/ ou operations/), sem manter cópias divergentes.
