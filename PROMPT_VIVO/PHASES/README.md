# PHASES — Modelos reutilizáveis de fase

Esta pasta contém instruções-modelo reutilizáveis. Elas não representam o estado de uma execução específica nem provam que uma fase foi executada.

## Como usar
1. Leia o README da execução em `runs/<RUN_ID>/`.
2. Consulte `PHASE_ARCHITECTURE.md` e `PHASE_CONTROL.md` para saber quais fases existem e qual gate está ativo.
3. Copie/adapte um modelo somente quando a execução precisar dele.
4. Registre alterações específicas na pasta da execução; não editar um modelo global para registrar resultados de uma run.

## O que salvar aqui
Somente instruções reutilizáveis de fase. Fontes, achados, checkpoints e estados reais pertencem à execução correspondente.
