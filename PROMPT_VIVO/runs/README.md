# Execuções do Prompt Vivo

Cada subpasta representa uma execução concreta. Não misturar pesquisas independentes na mesma pasta sem uma razão documentada.

## Convenção de ID
`PV-AAAA-MM-DD-TEMA-CURTO`

## Início
Copiar os arquivos definidos em `../RUN_TEMPLATE.md`, adaptar ao objetivo e registrar o ID nesta lista e em `operations/state.toml` quando for a execução ativa.

## Continuidade
Antes de criar nova execução, verificar se já existe uma execução ativa para o mesmo objetivo. Ler o README da execução, `RESUME_PACKET.md` e `RUN_STATE.md`; consultar `MEMORY_HANDOFF.md` apenas quando necessário.
