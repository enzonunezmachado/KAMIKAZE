# Execuções do Prompt Vivo

Cada subpasta representa uma execução concreta. Não misturar pesquisas independentes na mesma pasta sem uma razão documentada.

## Convenção de ID
`PV-AAAA-MM-DD-TEMA-CURTO`

## Início
Copiar os arquivos definidos em `../RUN_TEMPLATE.md`, adaptar ao objetivo e registrar o ID nesta pasta ou em `INDEX.md`.

## Continuidade
Antes de criar nova execução, verificar se já existe uma execução ativa para o mesmo objetivo. Ler `RUN_STATE.md` e `MEMORY_HANDOFF.md` para retomar.
