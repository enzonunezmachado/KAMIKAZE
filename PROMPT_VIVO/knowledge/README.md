# Base de conhecimento especializado

Esta pasta contém módulos reutilizáveis de conhecimento por domínio, criados quando pesquisas justificarem especialização.

## Estrutura recomendada
`knowledge/<DOMINIO>/README.md` com:
- escopo do domínio;
- conceitos e glossário;
- atores e cadeia de valor;
- modelos de negócio;
- métricas;
- fontes de referência;
- riscos e regulamentação;
- métodos de análise;
- dados temporais e data da última revisão;
- perguntas ainda abertas.

Não criar uma especialização vazia ou especulativa. O conteúdo deve nascer de pesquisa documentada e distinguir conhecimento duradouro de informação que envelhece.
