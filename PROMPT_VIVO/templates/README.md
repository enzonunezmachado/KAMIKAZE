# Templates auxiliares

Guardar aqui modelos reutilizáveis que não pertencem ao protocolo central, como ficha de concorrente, entrevista, análise de oferta, cálculo de margem, mapa de jornada ou auditoria de ferramenta.

Antes de criar um template, verificar se o RUN_TEMPLATE ou os arquivos de fase já cobrem a necessidade.
