# Modelo de execução Prompt Vivo

Copiar esta estrutura para `runs/<RUN_ID>/` e preencher conforme o trabalho.

## Arquivos a criar

### RUN_STATE.md
- ID:
- Título:
- Objetivo:
- Criado em:
- Última atualização:
- Estado:
- Fase atual:
- Fases concluídas:
- Próxima ação exata:
- Bloqueios/decisões humanas:
- Links para arquivos centrais:

### RESEARCH_PLAN.md
- Pergunta principal:
- Perguntas secundárias:
- Escopo incluído:
- Escopo excluído:
- Janela temporal/geográfica:
- Hipóteses iniciais:
- Critérios de decisão:
- Frentes de pesquisa:
- Métodos e ferramentas disponíveis:
- Critérios de parada:

### SOURCE_LEDGER.md
Tabela sugerida: ID | Fonte | URL | Tipo | Publicação | Consulta | Afirmação sustentada | Status | Limitações.

### FINDINGS.md
Agrupar por pergunta. Para cada achado: afirmação, tipo de evidência, fontes, confiança, contraprovas e implicação.

### OPEN_QUESTIONS.md
Lista priorizada de perguntas pendentes, motivo, impacto na decisão, método sugerido e status.

### MEMORY_HANDOFF.md
Resumo de continuidade para outro chat conforme MEMORY_AND_HANDOFF.md.

### FINAL_SYNTHESIS.md
Resumo executivo, método, conclusões, evidências, contraprovas, limitações, decisão, próximos passos e anexos.

## Regra

Não preencher campos com invenções. Se a informação ainda não existe, registrar como pendente ou desconhecida.
