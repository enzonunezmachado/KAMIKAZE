# Operations — Índice operacional do Kamikaze

Esta pasta contém controles de execução e registros estruturados da operação. Não é a base de conhecimento metodológica nem o histórico de pesquisa.

## Leitura obrigatória
1. [Estado operacional](STATE.md) — execução ativa, restrições, recursos e ponteiros.
2. [Recursos disponíveis](AVAILABLE_RESOURCES.md) — inventário de ferramentas e capacidades.
3. [Company Solutions](COMPANY_SOLUTIONS/README.md) — diagnóstico e gestão de empresas; ler seu próprio README antes de operar.

## Regras de gravação
- Estado atual fica em STATE.md; não copiar o estado detalhado de uma execução para este índice.
- Registros de empresas, contatos, projetos, contratos e finanças pertencem exclusivamente a COMPANY_SOLUTIONS.
- Não inserir senhas, tokens, dados pessoais desnecessários ou segredos.
- Não iniciar contatos, propostas, contratos, despesas ou deploys sem autorização.
